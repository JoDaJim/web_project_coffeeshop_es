Website Cafeteria Triple Espresso

Página web destinada a la clientela de la cafetería “Triple Espresso”, cuyo propósito es brindar un servicio de reservas para el local, así como proporcionar información relevante sobre el negocio.

Para el desarrollo de este proyecto se utilizaron HTML5 y CSS3 para estructurar y diseñar la página. Se implementó Flexbox para organizar y distribuir los elementos de la interfaz, además de formularios para permitir a los usuarios realizar reservas. También se utilizaron fuentes de código abierto proporcionadas por Google Fonts, junto con otros recursos necesarios para complementar el diseño y la funcionalidad del sitio.
